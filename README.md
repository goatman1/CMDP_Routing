# EAFR–OMD experiments for constrained online learning

This repository contains the reproducibility artifact for the synthetic mechanism experiments in **“When Should an Online Learner Trust Uncalibrated Forecasts? Error-Adaptive Learning in Constrained MDPs.”**

The experiments evaluate Error-Adaptive Feasible Replanning with an online mirror-descent reference (**EAFR–OMD**) and its strongly adaptive wrapper (**SA–EAFR–OMD**). They isolate three claims from the paper:

1. stage-selective forecast trust under a shared resource constraint;
2. recovery when forecasts change from adversarially wrong to exact; and
3. learning an unknown mean resource cost from stochastic observations.

All environments are synthetic. Loss, regret, forecast-induced downside, and resource violation are computed from exact occupancy probabilities. No external dataset, pretrained model, network service, or GPU is required.

## Repository contents

- `experiments/run_experiments.py` runs the three mechanism tests, regenerates the paper figure, and writes all summaries and numerical checks.
- `experiments/verify_occupancies.py` independently audits prefix-preserving occupancy reconstruction on small stochastic-transition CMDPs.
- `experiments/results/` contains the recorded raw arrays, summaries, paired comparisons, and verification records used for the manuscript.
- `figures/mechanisms.pdf` and `figures/mechanisms.png` are regenerated by the main experiment script.

The detailed protocol and interpretation limits are documented in [`experiments/README.md`](experiments/README.md).

## Reproduction

The recorded run used Python 3.8.2. Create an isolated environment and install the pinned numerical dependencies:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r experiments/requirements.txt
```

Run the experiments and the independent occupancy audit from the repository root:

```bash
python experiments/run_experiments.py
python experiments/verify_occupancies.py
```

The recorded full run takes about 30 seconds on a CPU. Runtime varies by solver and hardware. A successful run prints a JSON verification report and overwrites the generated files in `experiments/results/` and `figures/`.

## Scope

These are controlled mechanism tests rather than a large routing benchmark. They do not establish empirical asymptotic rates or physical battery safety. The resource metric is cumulative positive expected-budget excess, and the synthetic forecasts satisfy the information assumptions stated in the paper.
